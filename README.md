# ParcelTracker Admin Dashboard

A frontend-only admin dashboard concept for a parcel tracking system built with **React**, **Vite**, **Tailwind CSS**, **shadcn/ui**, and **React Router**.

I started this project after a frontend job interview as a way to practice building an admin dashboard and improve my React skills. I only had a few days to work on it, so many planned features are unfinished, but I wanted to upload it to showcase my approach to component structure, routing, and data tables.

## Current Features

* Dashboard layout
* Parcel table using dummy JSON data
* Search functionality
* Filter parcels by status
* Action dropdown

  * Copy tracking number
  * Navigate to a parcel details page
* Basic routing with React Router
* Edit package modal

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rgoles/parcelTrack.git
```

### 2. Navigate to the project directory

```bash
cd ParcelTrack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the URL displayed in your terminal (typically `http://localhost:5173`) in your browser.

## Troubleshooting

If the application doesn't update correctly or you encounter unexpected behavior, perform an **Empty Cache and Hard Reload** in your browser.
